## Expense Tracker
A full-stack MERN (MongoDB, Express.js, React.js, Node.js) web application, Expense Tracker, designed to help users manage and track their expenses effectively. The application enables users to add, categorize, update, and delete expenses, while visualizing their spending patterns over time.

## Features
- Add, update, and delete expenses
- Categorize expenses for better tracking
- View expense history
- Data storage with MongoDB for enhanced accuracy and reduced errors
- User-friendly interface built with ReactJS, Html, Javascript

## Technologies Used
- **Frontend**: HTML, CSS, JavaScript, ReactJS
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Architecture**: MERN Stack (MongoDB, Express.js, React.js, Node.js)
